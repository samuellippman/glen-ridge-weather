Sources: National Weather Service (api.weather.gov, NDFD grid OKX 26,45) and the GFS, ECMWF IFS, ICON, UKMO and GEM models via Open-Meteo (open-meteo.com), plus Open-Meteo's own "best match" blend. Data is fetched live from these public APIs every time this page loads — nothing is cached or hardcoded. Forecast models generally only cover roughly the next 1–16 days (varies by model) and a few months of recent history; dates outside a model's range will show as unavailable for that model. Consumer sites (Weather.com, AccuWeather, Weather Underground, etc.) were checked but render forecasts via JavaScript that can't be scraped headlessly — they re-package these same underlying models rather than offering independent data, so this comparison uses the models directly.
